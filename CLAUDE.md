# CLAUDE.md

Контекст для Claude Code при работе в этом репозитории.

Весь контент — в @AGENTS.md, общем для любого агента (Codex, Claude Code и
т.д.). Отличий для Claude Code сейчас нет.

Комментарии в миграциях из истории (теги `pre-baseline-migrations*`) и
несколько комментариев внутри тел функций, перенесённых в baseline дословно,
ссылаются на «Грабли в CLAUDE.md» и на «Конвенции работы в CLAUDE.md» —
имеется в виду AGENTS.md. Так сложилось исторически: файл был один,
содержимое переехало, а комментарии в уже накатанных миграциях не
переписывались — это журнал, а не живой документ. Тела функций baseline
обязаны совпадать с production байт в байт, поэтому их не правят ради ссылки.
В самих `docs/` и в README ссылки ведут прямо в AGENTS.md.
